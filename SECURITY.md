# Security Policy

## Supported Versions

Security updates are provided for the latest released version of LibrePhotos.
Please confirm that a vulnerability is still present in the latest release when
possible. Reports about older versions are still welcome, especially when the
issue also affects the current release.

## Reporting a Vulnerability

Please do not report security vulnerabilities in a public GitHub issue or
discussion.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/LibrePhotos/librephotos/security/advisories/new).
Include as much of the following information as possible:

- The affected LibrePhotos version and installation method
- A description of the vulnerability and its potential impact
- Steps to reproduce the issue or a minimal proof of concept
- Any known mitigations or suggested fixes
- Your preferences for attribution and coordinated disclosure

Please avoid accessing data that is not your own, disrupting services, or
publicly disclosing the vulnerability before a fix is available.

## What to Expect

The maintainers aim to acknowledge a report within 7 days and provide an
initial status update within 14 days. Resolution time depends on the severity
and complexity of the issue. The maintainers will coordinate with you on a fix
and an appropriate disclosure timeline.
