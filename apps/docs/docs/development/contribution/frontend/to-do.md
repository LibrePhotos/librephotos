You can look into the issues [here](https://github.com/LibrePhotos/librephotos/issues?q=is%3Aopen+is%3Aissue+label%3Afrontend),
on what features are missing from the frontend.

End-to-end tests live in `apps/frontend/e2e`. They are a [Playwright](https://playwright.dev/) smoke
suite (login, timeline, lightbox, favorites, logout); see
[End-to-end tests](./index.md#end-to-end-tests) for how to run them. Organizing flows such as
duplicates, stacks and user settings are not covered yet, and more coverage is very welcome.

You can also help by expanding the documentation.
