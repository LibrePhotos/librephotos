## How this table is made

Each app's source code, documentation and release notes were read on 2026-11-13; for the closed-source apps (Google Photos, Synology Photos, PhotoStructure) only their official help pages were used. The version that was looked at is in the tooltip of each app's name. Cells with an <i>i</i> carry a note: hover over them, or turn on **Show notes**.

Apps change quickly, and some answers depend on configuration, hardware or a paid tier. If you find a cell that is wrong or out of date, edit [`src/data/feature-comparison.json`](https://github.com/LibrePhotos/librephotos/blob/dev/apps/docs/src/data/feature-comparison.json) and open a pull request with a link to the source that shows it.
