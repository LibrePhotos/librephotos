Use cases

Who LibrePhotos is for, and what it does for them today.

LibrePhotos is a self-hosted photo server for the library you already have. These pages look at it from four kinds of people who use it, with the problems they bring, the features that answer them, and the things it does not do yet.

Photographers

Hobby and semi-pro photographers who shoot RAW, rate and keyword in digiKam, darktable or Lightroom, and want the library on a server of their own.

  • RAW+JPEG pairs shown as one photo
  • Ratings, keywords and captions read from XMP sidecars, and written back if you choose
  • Search by camera, lens, aperture, ISO and focal length
LibrePhotos for photographers

Archivists and family historians

People who keep a family archive, a local history collection or a club's photos, and need the files to stay where they are and the knowledge to stay in the files.

  • Folders indexed in place, nothing reorganised
  • Dates, captions, locations, rights and named faces in standard XMP
  • Faces, places and the text on scanned documents made searchable
LibrePhotos for archivists and family historians

Families

Households that want one place for everyone's photos at home, with an account for each person and sharing they decide on themselves.

  • An account and a library for each person
  • Share an album, a person or a whole library with each other
  • Faces, places, events and memories made for you
LibrePhotos for families

Self-hosters and homelab users

People who run their own services and want a photo server that keeps photos, faces and search on their own hardware.

  • Machine learning runs on your server, place names offline by default
  • Docker, Kubernetes, Unraid or a Windows program; SQLite or PostgreSQL
  • Single sign-on with OpenID Connect, a REST API and management commands
LibrePhotos for self-hosters and homelab users

Who it is not for yet

Saying so now saves you a migration later. Each of these may change; the issue tracker and the release notes say when.

Phone-first households

If what you need most is automatic backup from every phone in the family, LibrePhotos does not have a released app of its own for that yet.

The official app is not published, and the third-party UhuruPhotos app for Android is in beta. See Mobile apps.

Schools, newsrooms and companies

Organisations that need several editors on one collection, roles beyond admin and user, two-factor sign-in or storage quotas will miss them today.

Every photo has one owner (#395). A club archive run from one shared account can work; see the archivists page.

End-to-end encryption

The server reads your photos to make thumbnails, find faces and search them, so whoever runs the server can see them.

LibrePhotos has no end-to-end encryption. Run it on hardware you trust.
